# TVK Councillor Portfolio

React + Vite + Tailwind CSS v4. The design system lives in `src/tailwind.css`, which is processed by the Tailwind Vite plugin.

Run:

    npm install
    npm run dev       # development
    npm run build     # production build in /dist

Edit your details in `src/data.js` (name, phone, WhatsApp, photo, stats, works, gallery).
Complaints are saved in the browser (localStorage). Connect a backend in `src/sections/Contact.jsx` (see TODO).
